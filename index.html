เมนูหลัก (หน้าภาพรวมระบบ E-Library)

ยินดีต้อนรับสู่ระบบห้องสมุดดิจิทัลของโรงเรียน รองรับการฝากไฟล์บน GitHub Pages ร่วมกับ Google Sheets

การบันทึกการเข้าใช้งานล่าสุด

ข้อมูลเมื่อกดปุ่มเข้าใช้งานจากหน้าแรกจะถูกส่งไปบันทึกลง Google Sheets เพื่อให้โรงเรียนนำไปสรุปยอดผู้ใช้บริการ

เวลาที่เข้าใช้ ชื่อ/รหัสประจำตัว ประเภท

ทางลัดการใช้งาน

เลือกเมนูที่ต้องการใช้งานจากรายการด้านล่างหรือแถบ Sidebar ด้านซ้าย

เมนูรายการหนังสือ

แสดงหน้าปกหนังสือเรียง 5 คอลัมน์ (บนจอขนาดใหญ่) จำนวน 20 รายการต่อหน้า พร้อมหมายเลขหน้า

เมนูยืม-คืน

บันทึกการยืมและคืนหนังสือ E-Library

ทำรายการยืมหนังสือ

รายการหนังสือที่กำลังยืมและรอคืน

รหัส ชื่อหนังสือ ผู้ยืม สถานะ / การจัดการ

เมนูเจ้าหน้าที่

สำหรับเจ้าหน้าที่เพื่อเพิ่มหนังสือ ตรวจสอบการยืม-คืน และดูประวัติการเข้าใช้งาน (ไม่รวมการตั้งค่าระบบ)

ยืนยันตัวตนเข้าสู่เมนูเจ้าหน้าที่

รหัสผ่านจะถูกตรวจสอบความถูกต้องผ่าน Google Apps Script โดยตรงเพื่อความปลอดภัย

จำนวนครั้งที่ผิด: 0 / 3 ครั้ง
🔒 รหัสเจ้าหน้าที่ถูกระงับการใช้งานชั่วคราว!
เนื่องจากมีการกรอกรหัสผิดเกิน 3 ครั้ง เพื่อความปลอดภัยของระบบ กรุณาติดต่อ Admin ผู้ดูแลระบบเพื่อทำการปลดล็อคให้ครับ
รหัสผ่านไม่ถูกต้อง กรุณาตรวจสอบและลองใหม่อีกครั้ง
สถานะการเข้าใช้งาน: เจ้าหน้าที่ห้องสมุด (สิทธิ์เพิ่มหนังสือและตรวจสอบการยืม-คืน)

เพิ่มหนังสือเข้าคลัง (สำหรับเจ้าหน้าที่)

ตรวจสอบและจัดการการยืม-คืนหนังสือ

รหัสหนังสือ ชื่อหนังสือ ผู้ยืม เวลาที่ยืม สถานะ / การจัดการ

ประวัติการกดปุ่มเข้าใช้งานระบบของโรงเรียน

ลำดับ วัน-เวลา ชื่อผู้เข้าใช้งาน / รหัส กลุ่มผู้ใช้

เมนู Admin

ใช้งานได้ครบทุกฟังก์ชัน: จัดการเพิ่มเจ้าหน้าที่ ปลดล็อคบัญชี เพิ่มรายการหนังสือ และตั้งค่าระบบ

ยืนยันตัวตนเข้าสู่เมนู Admin

รหัสผ่านจะถูกเก็บและตรวจสอบบน Google Apps Script (Script Properties) โดยตรง ไม่มีรหัสฝังในไฟล์ HTML

จำนวนครั้งที่ผิด: 0 / 3 ครั้ง
🔒 รหัส Admin ถูกระงับการใช้งานชั่วคราว!
เนื่องจากมีการกรอกรหัส Admin ผิดเกิน 3 ครั้ง ระบบได้ระงับการเข้าสู่หน้า Admin ผ่านเว็บไซต์โดยอัตโนมัติ
📌 วิธีการปลดล็อครหัส Admin ที่ถูกล็อค:
  1. เปิดไฟล์ Google Sheets E-Library Database ของโรงเรียน
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  3. ที่แถบเครื่องมือด้านบน ในช่องเลือกชื่อฟังก์ชัน ให้เลือกฟังก์ชัน unlockAdminAccount
  4. กดปุ่ม เรียกใช้ (Run) จำนวน 1 ครั้ง
  5. ระบบจะรีเซ็ตจำนวนครั้งที่ผิดเป็น 0 และปลดล็อคให้ Admin สามารถกลับมาล็อกอินบนหน้าเว็บได้ทันทีครับ
รหัส Admin ไม่ถูกต้อง กรุณาตรวจสอบและลองใหม่อีกครั้ง
สถานะการเข้าใช้งาน: ผู้ดูแลระบบสูงสุด (Admin - สิทธิ์เต็มทุกฟังก์ชัน)

การจัดการความปลอดภัยและปลดล็อครหัสผ่าน

สถานะรหัสเจ้าหน้าที่: ปกติ (0/3)

เพิ่มเจ้าหน้าที่ห้องสมุด

กำหนดชื่อและรหัสผ่านสำหรับเจ้าหน้าที่ใหม่ โดยข้อมูลจะบันทึกลงแผ่นงาน StaffAccounts ใน Google Sheets

รายชื่อเจ้าหน้าที่ในระบบ

รหัส ชื่อเจ้าหน้าที่ การจัดการ

เพิ่มหนังสือเข้าคลัง

ตั้งค่าเชื่อมต่อ Google Apps Script (Web App URL)

วาง Web App URL ที่ได้จากขั้นตอน Deploy ใน Google Apps Script เพื่อให้ระบบเชื่อมกับ Google Sheets จริง

ตัวอย่างโค้ด Google Apps Script (ฉบับสมบูรณ์พร้อมระบบความปลอดภัย):
// วางโค้ดนี้ใน Apps Script > กด Run setupDatabase > Deploy as Web App function setupDatabase() { const ss = SpreadsheetApp.getActiveSpreadsheet(); const sheets = { 'Books': ['id', 'title', 'author', 'category', 'status', 'cover_url', 'pdf_url'], 'AccessLogs': ['timestamp', 'name', 'role', 'action'], 'BorrowLogs': ['bookId', 'bookTitle', 'borrower', 'borrowedAt', 'status'], 'StaffAccounts': ['id', 'name', 'pin', 'isDefault'] }; for (let s in sheets) { if (!ss.getSheetByName(s)) { const sh = ss.insertSheet(s); sh.appendRow(sheets[s]); } } const p = PropertiesService.getScriptProperties(); if (!p.getProperty('STAFF_PIN')) p.setProperty('STAFF_PIN', 'กำหนดรหัสผ่านเจ้าหน้าที่ตรงนี้'); if (!p.getProperty('ADMIN_PIN')) p.setProperty('ADMIN_PIN', 'กำหนดรหัสผ่านแอดมินตรงนี้'); if (!p.getProperty('STAFF_FAILS')) p.setProperty('STAFF_FAILS', '0'); if (!p.getProperty('ADMIN_FAILS')) p.setProperty('ADMIN_FAILS', '0'); if (!p.getProperty('STAFF_LOCKED')) p.setProperty('STAFF_LOCKED', 'FALSE'); if (!p.getProperty('ADMIN_LOCKED')) p.setProperty('ADMIN_LOCKED', 'FALSE'); } function unlockAdminAccount() { const p = PropertiesService.getScriptProperties(); p.setProperty('ADMIN_FAILS', '0'); p.setProperty('ADMIN_LOCKED', 'FALSE'); }
